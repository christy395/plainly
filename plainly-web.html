Everything runs in your browser and nothing is sent anywhere. Your program is turned into JavaScript, which browsers run very fast, and it can only do what Plainly allows: no files, no network. Pages built here are live: headings, text, boxes and buttons. If something goes wrong, a Fix it button appears when I can repair it.
